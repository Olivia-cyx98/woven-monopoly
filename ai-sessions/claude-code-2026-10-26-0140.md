module WovenMonopoly
  # The ring of spaces players move around. GO is the first space.
  class Board
    Move = Struct.new(:position, :passed_go, keyword_init: true)

    attr_reader :spaces

    def initialize(spaces)
      raise ArgumentError, 'Board must have at least one space' if spaces.empty?

      @spaces = spaces
    end

    def size
      spaces.size
    end

    def space_at(position)
      spaces.fetch(position)
    end

    def move(from, roll)
      total = from + roll
      Move.new(position: total % size, passed_go: total >= size)
    end

    def colour_group(colour)
      spaces.select { |space| space.property? && space.colour == colour }
    end
  end
end

No, keep it in `spec/`. That's the standard RSpec layout:

- **`spec/spec_helper.rb`** is the entry point. `.rspec` loads it before every run (`--require spec_helper` looks in `spec/`), and `rspec --init` creates it there.
- **`spec/support/`** holds the small helpers that `spec_helper.rb` loads, like your `TestBoard`.

In other words, `spec_helper` loads `support/`, so it shouldn't live inside it.

Moving it there would break the setup unless you changed three things:
1. `.rspec` would need `--require support/spec_helper`.
2. `require_relative '../lib/woven_monopoly'` would need to become `'../../lib/woven_monopoly'`.
3. The `Dir[...]` line would search `spec/support/support/` and find nothing, so you'd have to rewrite it. It would also pick up `spec_helper.rb` itself.

That's extra work for a layout reviewers won't expect, so I'd leave it where it is now.
