# Copilot inline suggestion setup

_Started 2026-10-24T02:30:40.277Z_

### User

how to enable the copliot inline suggestion

### Claude

Here's how to turn on GitHub Copilot inline suggestions (ghost text) in VS Code:

**1. Install and sign in**
- Open Extensions (`Cmd+Shift+X`) and install **GitHub Copilot**. Copilot Chat usually installs alongside it.
- Click the Copilot icon in the status bar, or the Accounts icon at the bottom left, and sign in with a GitHub account that has Copilot access. The free tier works.

**2. Turn on inline suggestions**
- Click the **Copilot icon in the status bar** (bottom right). Make sure completions are turned on for all files or for the current language.
- Or open Settings (`Cmd+,`), search for `copilot enable`, and check that `github.copilot.enable` isn't set to `false` for your language. In `settings.json` it looks like this:
  ```json
  "github.copilot.enable": {
    "*": true,
    "markdown": true,
    "plaintext": false
  },
  "editor.inlineSuggest.enabled": true
  ```
- Make sure **`editor.inlineSuggest.enabled`** is `true`. This is VS Code's own inline-suggestion switch, and Copilot needs it.

**Note:** Copilot turns inline suggestions **off for Markdown by default**. You have `README.md` open, so if you don't see suggestions there, set `"markdown": true` as shown above.

**3. Use the suggestions**
- `Tab` accepts a suggestion and `Esc` dismisses it.
- `Option+]` / `Option+[` cycle through other suggestions.
- `Cmd+→` accepts one word at a time.
- `Option+\` asks for a suggestion manually.

**If suggestions still don't appear**
- Check the Copilot status bar icon for an error or a "disabled" state.
- Run **"GitHub Copilot: Collect Diagnostics"** from the Command Palette (`Cmd+Shift+P`).
- Reload the window with **Developer: Reload Window**.
